Astro SSA

Distributed platform for Space Situational Awareness (SSA) and data mitigation for astronomy. Real-time orbital prediction and interference analysis for scientific observatories.

Protecting astronomical viewing

The exponential growth of satellite constellations in Low Earth Orbit (LEO) threatens the integrity of scientific observations. Astro was created as an open-source, distributed-computing solution to mitigate this impact.

Through a native Python SDK and a high-availability REST API (FastAPI), our orchestration engine ingests TLE data, projects trajectories, and executes advanced geometric algorithms (such as the modeling of exclusion polygons). The system is designed to alert observatories before a satellite transit compromises the acquisition of scientific data or precision astrophotography.
